# Kursi Clash (Kotlin / Android)

Landscape 2D fighting game (satire theme) with original fictional characters.

## Run
1. Android Studio (Koala or newer) -> File > Open -> this folder. Let Gradle sync.
2. Run on a device/emulator (minSdk 24).

## Controls
Touch: left pad = move/jump/crouch, right = PUNCH / KICK / GRAB / SUPER.
Keyboard (emulator): A/D move, W jump, S crouch, J punch, K kick, I grab, L/Space super.
Hold back = block. Combos: P,P,P / P,P,K / P,K / K,K. Crouch+K = sweep, Crouch+P = uppercut.
